부정 조건 검사는 합성 증거를 사용하는 단위테스트다. 실제 후보 업로드는 정상 CI에서 확인했다. APK 실행은 API 29 에뮬레이터에서 확인했으며, 내려받은 묶음의 POS smoke test를 삼성 기기/LAN 성공으로 확대하지 않는다.

## 남은 작업

OPUS의 M2 검토 결과 반영, 삼성 실기기 설치·LAN 관측, 실제 영상 촬영·편집·지원 자료 최종 확정이 남아 있다. 후보는 debug 시험 제어를 포함하는 통제된 시연용이며 CI 성공이 독립 검토 승인이나 운영 서명·실매장 배포를 뜻하지 않는다. [실행 안내](../DEMO_QUICKSTART.md), [촬영 계획](../DEMO_VIDEO.md), [지원 설명 초안](../PORTFOLIO.md)을 사용한다.
