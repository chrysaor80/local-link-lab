## 검증 과정에서 수정한 점

- 첫 CI는 SDK 설치 도구의 기본 `tools` 패키지가 더 이상 제공되지 않아 중단됐다. 필요한 SDK/빌드 도구를 명시했다.
- 다음 CI는 Android 4개를 통과했지만 테스트 도구가 앱을 제거해 결과 추출에 실패했다. 최종 판정기는 성공으로 처리하지 않았고 전체 실행이 실패했다. 검사 종료 후 APK 보존 옵션을 적용한 새 실행에서 최종 대조까지 통과했다.
- 소스·테스트·DB가 연결된 근거를 남기며 단순 빌드 성공을 정상 왕복 성공으로 대체하지 않았다.

## 아직 증명하지 않은 것

삼성 실기기, 사용자 PC의 방화벽과 LAN, API 23 실행, 실제 OS 프로세스 종료/복원, Android 장애 3종, 결함 사본 2종, 실제 저장 공간 고갈, 업데이트/마이그레이션, 기기 이전 차단의 OS별 동작은 NOT_RUN이다. DB 객체를 다시 연 테스트를 프로세스 종료 테스트로 부르지 않는다. M1 정상 왕복 완료는 v0.1 전체 완료를 뜻하지 않는다.
