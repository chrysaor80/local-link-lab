## 테스트 자체의 검출 확인

정상 6개가 먼저 통과한 동일 소스에서 별도의 임시 사본을 만들었다. 제품 소스나 APK에 결함 선택 스위치를 넣지 않았다. 정상 실행에서 사용한 외부 실행기와 판정기를 그대로 사용했다.

| 사본 | 변경 | 빌드·설치 | 실제 검출 | 판정 |
|---|---|---|---|---|
| MUT01 | 재시도 때 새 요청 ID 생성 | 성공 | `POS_EXTRA_ID`: 기준에 없는 추가 주문 | KILLED |
| MUT02 | ACK를 받기 전에 로컬 완료 저장 | 성공 | `ACK_WITHOUT_POS`: POS에 없는 주문을 완료로 기록 | KILLED |

빌드 오류·명령 실패·환경 문제로 실패한 것을 KILLED로 계산하지 않았다. 두 경우 모두 실제 앱을 실행했고, 예상한 데이터 불변식 위반으로 시나리오가 FAIL이었다. 사본 실행 후 정상 APK를 다시 설치했다.
